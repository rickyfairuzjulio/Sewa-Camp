# Sewa-Camp
Website Sistem Informasi Penyewaan Alat Camping merupakan aplikasi berbasis web dengan tiga role, yaitu Admin, Petugas, dan Pelanggan. Sistem ini menyediakan fitur pengelolaan inventaris, katalog alat, paket camping, pemesanan, pembayaran online, pengembalian, perawatan alat, serta laporan transaksi.
